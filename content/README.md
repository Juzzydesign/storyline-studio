# Content

Drafts and published pieces across Storyline channels.

| Folder | Use for |
| --- | --- |
| `packages/` | Briefs / hubs for each idea — start here |
| `youtube/` | Video outlines, scripts, titles, and cut notes |
| `newsletters/` | Newsletter drafts and send archives |
| `articles/` | Long-form posts and essays |
| `linkedin/` | LinkedIn posts and carousels |

## Flow

1. Create a package from `packages/_template.md`
2. Write finished drafts in the channel folders
3. Use the same **ID** across package, drafts, and assets
4. Link drafts and assets back in the package

Name files by date + slug when useful, e.g. `2026-11-12-framework-mistakes.md`.
