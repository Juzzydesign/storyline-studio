# Packages

Hub for each content idea. One package = one piece that may ship across channels.

## How to use

1. Duplicate `_template.md`
2. Name it `YYYY-MM-slug.md` (or match the **ID**)
3. Fill claim, audience, channels, assets
4. Write drafts in `content/articles/`, `youtube/`, etc.
5. Link those drafts back here

Do not write the full article inside the package — keep this as the brief and index.
