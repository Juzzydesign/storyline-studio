# Assets

Reusable creative files that sit outside the Next.js `public/` folder.

| Folder | Use for |
| --- | --- |
| `diagrams/` | Flowcharts, process maps, and node diagrams |
| `illustrations/` | Illustrations and supporting visuals |
| `templates/` | Figma / layout templates for recurring formats |

Web-served images for the studio UI still live in `public/`. Put source and archive files here.

When exporting from Figma, prefer filenames that include the content package **ID**, and register them in `manifest.json`.
