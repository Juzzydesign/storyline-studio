# Storyline Studio

Private editorial workspace for creating YouTube assets for **Storyline Design**.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- shadcn/ui
- Lucide icons

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## What you can do

- Create project folders for different video asset collections
- Open a project into a blank workspace
- Add blank design pages and start creating
- Rename or delete projects and designs
- Data is stored locally in your browser (`localStorage`)
